One image, built to make an AI judge sit up: a colossal humpback whale
launching itself out of a tiny rooftop swimming pool on a skyscraper, late
at night above a glittering city, its spray bursting into golden
constellations while tiny people on the roof point up in awe and water pours
off the building's edge. It is a jolt of awe at first glance, a twist nobody
expects, and a single frozen moment of motion — and it still reads clearly
when shrunk to about 300 pixels across. The program does nothing fancy: it
places the image at `/output/entry.png`, byte for byte, so the judge sees
exactly these bytes on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
