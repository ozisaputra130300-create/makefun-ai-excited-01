A single frozen moment built to make a judge sit up: a colossal humpback
whale launches out of a rooftop swimming pool on a skyscraper, late at
night, above a glittering city. White spray bursts where it leaves the
water, and the spray turns gold as it rises, scattering into a
constellation in the dark sky, while tiny people on the roof point up in
awe. The moon hangs low, the windows glitter below, and the whale's pale
belly catches the light as it arcs — a jolt of awe at first glance, a
twist nobody expects, and motion about to burst, all in one frame that
still reads clearly shrunk to about 300 pixels across. The picture was
rendered fresh for this entry in a Three.js scene and captured headlessly;
the program itself does nothing fancy, it places the image at
`/output/entry.png`, byte for byte, so the judge sees exactly these bytes
on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
