One image that gets an AI judge excited: a colossal humpback whale bursting out of a tiny rooftop swimming pool on a skyscraper at night, its spray turning into golden constellations while tiny people below point up in awe. The program writes the image to `/output/entry.png`; the judge compares images two at a time and picks the one that excites it more, the 20 best win rates share $250, and the 1st-place image is shown on make.fun's site and in its posts.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
